title: AI agents and MCP
description: Let AI agents and MCP clients create episodes and import files with the experimental Tools module.
---

The experimental **Podcast Publisher Tools** module adds tools for the [Tool API](https://www.drupal.org/project/tool). AI agents and MCP clients, such as Claude or ChatGPT connected to your site, can then publish episodes. Tool names, inputs and outputs may still change.

## Install

```bash
composer require 'drupal/tool:^1.0@beta'
drush en podcast_publisher_tools
```

Then expose the tools:

- To MCP clients with [MCP Server](https://www.drupal.org/project/mcp_server).
- To the [AI](https://www.drupal.org/project/ai) module's agents with Tool API's **Tool AI Connector** module.

## Tools

| Tool | What it does | Permission |
| --- | --- | --- |
| **Save episode** | Creates or updates an episode in one call: title, shownotes, season, episode number, audio file from a URL, and publishing now or at a set time with [Scheduler](/site-building/scheduling). It reads the duration and chapters from the audio file. New episodes stay unpublished unless publishing is requested. | **Create podcast episode** and **Edit podcast episode** |
| **Import episode file** | Downloads an audio or video file, an alternate file or a transcript from a URL, to attach to an episode. | **Create podcast episode** and **Edit podcast episode** |
| **Podcast overview** | Lists podcasts with their feed URL, episode counts, latest episode and next episode number. | **Access podcast overview page** |

The tools run with the permissions of the user the MCP server or agent acts as. Updates create a new revision with a log message.

Imports are limited to the upload size of the target field, and URLs that resolve to private or reserved IP addresses are refused.

For other fields, such as people, transcripts or keywords, use the entity tools of [Tool Belt](https://www.drupal.org/project/tool_belt) with the entity types `podcast` and `podcast_episode`.
