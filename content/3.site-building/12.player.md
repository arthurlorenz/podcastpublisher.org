---
title: Add an episode player
description: Play episodes in the browser with the Podlove Web Player module, or with Drupal's built-in HTML5 audio player.
---

Podcast Publisher does not ship a player. An episode page shows the fields you enable, and the audio file can use a field formatter: Drupal's built-in **Audio** format is a plain HTML5 player, and the [Podlove Web Player](https://www.drupal.org/project/podlove) module adds a player with the podcast and episode artwork, the shownotes, and a subscribe button.

## Install the Podlove Web Player

The module needs Podcast Publisher 1.0.0-alpha11 or later. It has no stable release yet, so require the development version:

```bash
composer require 'drupal/podlove:^1.0@dev'
drush en podlove
```

The player script loads from `cdn.podlove.org`, so visitors' browsers contact podlove.org when they open an episode page. Cover this in your privacy policy or consent banner if your site needs to.

## Show the player on episode pages

Follow [Show the audio player and shownotes](/site-building/fields-and-display#show-the-audio-player-and-shownotes), but set the **Audio File** format to **Podlove Web Player** instead of **Audio**.

## Choose the apps in the subscribe button

The subscribe button links the podcast's feed and lists the podcast apps you pick per podcast. The module adds a **Podlove Client settings** field to podcasts for this, but doesn't put it on the form.

1. Open **Structure → Podcasts → Manage form display** (`/admin/structure/podcast/form-display`).
2. Move **Podlove Client settings** from the **Disabled** section into the content region, and click **Save**.
3. Edit a podcast, check the apps to list, and save it.

## Website plays and analytics

The Podlove Web Player always plays the episode's plain file URL, not the **Download Tracker URL**. Plays in the player are not counted in [analytics](/analytics).
