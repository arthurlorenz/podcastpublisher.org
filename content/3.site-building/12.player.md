---
title: Add an episode player
description: Play episodes in the browser with the Podlove Web Player module, or with Drupal's built-in HTML5 audio player.
---

Podcast Publisher does not ship a player. An episode page shows the fields you enable, and the audio file can use a field formatter: Drupal's built-in **Audio** format is a plain HTML5 player, and the [Podlove Web Player](https://www.drupal.org/project/podlove) module adds a full player with chapters, transcripts and sharing.

## Install the Podlove Web Player

The module needs Podcast Publisher 1.0.0-alpha11 or later. It has no stable release yet, so require the development version:

```bash
composer require 'drupal/podlove:^1.0@dev'
drush en podlove
```

## Show the player on episode pages

1. Open **Structure → Podcast Episode → Manage display** (`/admin/structure/podcast-episode/display`).
2. Move **Audio File** from the **Disabled** section into the content region.
3. Set the **Audio File** format to **Podlove Web Player**.
4. Optionally, move **Transcripts** too and set its format to **Generic file** to link the transcript files.
5. Click **Save**.

If you use [episode pages](/get-started/episode-page), open **Manage display** for the Podcast Episode Page content type and set the **Podcast Episode** field's format to **Rendered entity**. The page then shows the episode with the display configured above.

To fall back to the plain HTML5 player instead, set the **Audio File** format to **Audio**. See [Fields and display](/site-building/fields-and-display#show-the-audio-player-and-shownotes).

## Website plays and analytics

The player uses the episode's uploaded file URL. Plays in the website's player are not counted in [analytics](/analytics) unless the player is fed the **Download Tracker URL** instead. See [Fields and display](/site-building/fields-and-display#show-the-audio-player-and-shownotes) for how to get the tracked URL.
