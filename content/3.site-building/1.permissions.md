---
title: Permissions
description: Give editors the access they need without granting full administration.
---

Assign permissions at **People → Permissions** (`/admin/people/permissions`). Podcast Publisher defines separate permissions for podcasts and episodes.

| Task | Permission |
| --- | --- |
| See the podcast list | **Access podcast overview page** |
| Create a podcast | **Create podcast** |
| View, edit, or delete a podcast | **View podcast**, **Edit podcast**, or **Delete podcast** |
| Create an episode | **Create podcast episode** |
| View, edit, or delete an episode | **View podcast episode**, **Edit podcast episode**, or **Delete podcast episode** |
| Configure podcast entity settings | **Administer podcast settings** |
| Configure episode entity settings and open analytics reports | **Administer podcast episode settings** |

The two **Administer** permissions also satisfy the module's create, edit, and delete access checks for their respective entity types. They grant broader access than a publishing role usually needs.

For an editor who creates both shows and episodes, start with the overview, create, view, and edit permissions for each entity. Add delete permissions only if that role should remove content. Creating **Podcast Episode Page** nodes also requires Drupal's separate content-type permissions.

The feed View's default access is unrestricted. Entity page access and the editor permissions above are separate from access to the RSS URL. Review your site and file access settings before distributing a feed.
