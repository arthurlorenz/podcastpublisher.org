---
title: Customize the feed
description: Change which fields fill the RSS tags, how many episodes appear, how episodes are identified, and how to lock or move the feed.
---

Each podcast's feed is the **Feed** display of the **Podcast Feed** View. Edit it at **Structure → Views → Podcast Feed** (`/admin/structure/views/view/podcast_feed`).

Change the View with care once the podcast is listed in directories. Apps read the feed every time they refresh, so a broken setting reaches subscribers quickly.

## How the View builds the feed

| Part | Default |
| --- | --- |
| Path | `podcast/%/feed.xml`, where `%` is the podcast ID |
| Contextual filter | Podcast ID |
| Filters | Published episodes of a published podcast |
| Sort | **Authored on**, newest first |
| Pager | None, so every episode is included |
| Caching | Tag based; saving a podcast or episode refreshes the feed |

The **Format** is **Podcast RSS Feed**, which writes the channel tags. **Show** is **Podcast Episode Fields**, which writes one `<item>` per episode. Each has a **Settings** dialog that maps View fields to feed tags.

## Channel tags

Open **Format: Podcast RSS Feed → Settings**.

| Setting | Feed tag | Default field |
| --- | --- | --- |
| Title field | `title` | Title |
| Description field | `description` | Summary |
| Subtitle field | `itunes:subtitle` | Subtitle |
| Summary field | `itunes:summary` | Summary |
| Image field | `itunes:image` | Image, using the `podcast_3000x3000` image style |
| Copyright field | `copyright` | Copyright |
| Type field | `itunes:type` | Type |
| Owner field, Email field | `itunes:owner` with `itunes:name` and `itunes:email` | Author, Email |
| Author field | `itunes:author` | Author |
| Category field | One `category` per comma-separated value | Category |
| Itunes Category field | `itunes:category`, nested under its parent category | iTunes Category |
| Block field | `itunes:block` | None |
| Explicit field | `itunes:explicit` | Explicit |
| Complete field | `itunes:complete` | Complete |
| Funding field | `podcast:funding` | Funding |
| License field, License URL field | `podcast:license` with `url` | License, License URL |
| Medium field | `podcast:medium` | Medium |
| People: name, role, link and image fields | One `podcast:person` per person, with `role`, `group`, `href` and `img` | The podcast's People, see [People](#people) |
| Publication date field | `pubDate` | Authored on |

A tag is left out when its field is empty. **Creator field** is not used in the feed.

`podcast:guid`, `podcast:locked` and `itunes:new-feed-url` come from the podcast's [ownership settings](#lock-or-move-the-feed), not from View fields.

Each episode whose **Type field** outputs `trailer` also adds a `podcast:trailer` to the channel, see [Trailers](#trailers).

## Episode tags

Open **Show: Podcast Episode Fields → Settings**.

| Setting | Feed tag | Default field |
| --- | --- | --- |
| Title field | `title`, `itunes:title` | Label |
| Link field | `link` | Link to the episode's page |
| Description field | `description`, `content:encoded` | Shownotes |
| File field, File size field, Mimetype field | `enclosure` with `url`, `length`, `type` | Audio File, with the **URL to file**, **File Length**, and **Mimetype** formatters |
| Duration field | `itunes:duration` | Duration, read from the audio file when the episode is saved |
| Image field | `itunes:image` | Image, using the `podcast_3000x3000` image style |
| Type field | `itunes:episodeType` | Type |
| Author field | `itunes:author` | Author |
| Explicit field | `itunes:explicit` | Explicit |
| Keywords field | `itunes:keywords` | Keywords |
| Publication date field | `pubDate` | Authored on |
| Episode number field | `itunes:episode` | Episode Number |
| Season field, Season name field | `itunes:season`, and `podcast:season` with `name` | Season, Season name |
| People: name, role, link and image fields | One `podcast:person` per person | The episode's People, see [People](#people) |
| Transcripts: file, mimetype and language fields | One `podcast:transcript` per file, with `url`, `type` and `language` | Transcripts, see [Transcripts](#transcripts) |
| GUID settings | `guid` | The episode's UUID, not marked as a permalink |

Dates must be in RFC 2822 format. The default date fields use the custom format `D, d M Y H:i:s T`; keep it if you replace them.

To count downloads, switch the **File field**'s formatter to **Download Tracker URL**. See [Analytics](/analytics#_3-track-feed-audio-urls).

## People

The People settings in the channel and the episode settings each map four View fields of the podcast's or episode's **People** reference field. Their values are matched by position:

| Setting | Attribute | Default formatter |
| --- | --- | --- |
| Person name field | Name | **Label**, without link |
| Person role field | `role` and `group` | **Field of the referenced entity**: Role |
| Person link field | `href` | **Field of the referenced entity**: Link |
| Person image field | `img` | **Field of the referenced entity**: Image |

- **Field of the referenced entity** outputs one field of each person as plain text: files, images, media and links as their absolute URL.
- A role of the form `group:role`, such as `visuals:cover art designer`, also sets `group`. Roles come from the [Podcast Taxonomy Project](https://github.com/Podcastindex-org/podcast-namespace/blob/main/taxonomy.json).
- An episode's people replace the podcast's people in apps, for that episode.

### Person images from Media

To use Media for person images, add a reference field to Media under **Structure → Podcast Person → Manage fields**. In the View, select that field in the formatter settings of both person image fields. For Image media, the feed uses the image; for other media, its thumbnail. Hide the **Image** field in **Manage form display**.

A recipe does the same with a field config, the form display, and the formatter settings of the two View fields.

## Trailers

A `podcast:trailer` has the same `url`, `type`, `length` and `pubdate` as the trailer episode's `enclosure` and `pubDate`, and the episode's `itunes:season` as `season`. With the **Download Tracker URL** formatter, trailer downloads are counted too. Apps preview the newest trailer.

Existing podcasts get the medium **Podcast** when you run `drush updatedb`, and the View gets the new fields.

## Transcripts

The three transcript settings map View fields of the episode's **Transcripts** field, matched by position like people. They use the **URL to file**, **Mimetype** and **Language code** formatters.

- VTT and SRT files have time codes, so their tags get `rel="captions"`. The type is `text/vtt` or `application/x-subrip`.
- `language` is left out for transcripts without a language. Apps then assume the feed's `<language>`.
- The URL is the plain file URL, not a [Download Tracker URL](/analytics), so transcripts are not counted as downloads.
- Web players that load transcripts from another domain need CORS headers on your files. Apps that read the feed on a server, such as Apple Podcasts, do not.

`drush updatedb` adds the Transcripts field to episodes and the three fields to the View.

## Use a different field

1. Add the field under **Fields** on the **Feed** display. Choose **This feed (override)** if the change should not affect other displays.
2. Pick a formatter that outputs plain text or a plain URL, such as **URL to file** or **Plain text**. Markup inside a tag breaks some apps.
3. Select the field in the channel or episode settings, then **Apply** and **Save** the View.

The settings only map fields to the tags listed above. Adding a tag that is not in the lists needs a template override or custom code.

## Limit the number of episodes

The feed lists every episode by default. To shorten it, set the **Feed** display's **Pager** to **Display a specified number of items**. Apps only show what the feed contains, so older episodes disappear from new subscribers' lists.

## Episode GUIDs

Podcast apps use each item's `guid` to recognize an episode. By default it is the episode's UUID, which never changes, even when you replace the audio file.

Sites that installed the module before this default keep the audio file's URL as the GUID. There, replacing an episode's audio file with a file at a different URL changes the GUID, and apps may show the episode again as new. Don't switch such a feed to the UUID: changing the GUID of existing episodes makes every app show them as new.

## Lock or move the feed

Edit a podcast and open **Feed ownership and moves**.

| Setting | Feed tag | What it does |
| --- | --- | --- |
| Podcast GUID | `podcast:guid` | Identifies the show across hosts and feed URLs. Generated from the feed URL when the feed is first requested, then stored and never changed. |
| Locked | `podcast:locked` with the podcast's **Email** as `owner` | Asks podcast platforms not to import the feed into another host. Platforms confirm a move with that email address. |
| Replaces an old feed | `itunes:new-feed-url` with this feed's URL | Tells Apple Podcasts that the show moved here. |
| New feed URL | None | Redirects this feed to the new URL with a 301. |

### Move a show to this site

1. Enter the show's existing GUID in **Podcast GUID**. Find it in the old feed's `podcast:guid` tag, or on [Podcast Index](https://podcastindex.org). Without it, the show gets a new GUID.
2. Check **Replaces an old feed**.
3. Redirect the old feed to the new one with a 301. Most hosts offer this when you leave them.
4. After at least four weeks, uncheck **Replaces an old feed**. Keep the redirect.

### Move a show away from this site

1. Unlock the feed if it is locked, so the new host can import it.
2. Enter the new feed URL in **New feed URL** and save. Apps and directories that request the old feed are redirected and follow the move.
3. Keep the podcast, and with it the redirect, for at least four weeks. Deleting the podcast ends the redirect.

## Change the feed template

The feed uses the `views-view-podcast-rss.html.twig` template from the module's `templates` directory. Copy it into your theme's `templates` directory and clear caches to override the channel markup. Episode items use Views' standard RSS row template.
